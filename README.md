# CPU KILLER

Root CPU control Android app by ANI STUDIO.

## v1.0
- Root detection
- CPU core count
- Kernel CPU max-frequency detection
- Performance profile UI
- Kernel control scan
- Thermal safety messaging
- Dark gaming-style UI

Actual overclocking is device/kernel dependent. CPU KILLER only uses controls exposed by the rooted kernel.

## Build
Open the project in Android Studio and build the app module.

Minimum Android: 8.0 (API 26)
Target SDK: 35
